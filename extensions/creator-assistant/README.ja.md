# Creator Assistant 0.3.0 · 达人助手

**アクセス権のあるプラットフォームページからクリエイターを記録し、フォロー状況と招待文案をブラウザー内で整理。**

ソースコード候補版です。ブラウザーと実際のプラットフォームでの受け入れ検証は完了していません。

作者：xiaoyu312 · [FateClear — 生年月日から命式の作成・解説を無料で利用できるサイト](https://fateclear.com) · [X — 作者のプロジェクトと更新情報](https://x.com/liu_xiaoyu27334)

単独で使える Manifest V3 拡張機能です。利用者が現在ログインしており、アクセス権を持つプラットフォームのページからクリエイター情報を記録し、フォロー状況、連絡先、絞り込み条件のブックマーク、招待文案を現在のブラウザー内に保存します。Douyin Selected Alliance（抖音精选联盟）、Weixin Channels（视频号）、Xiaohongshu Pugongying（小紅書蒲公英）、Kuaishou（快手）に対応する処理を含みます。Douyin と Weixin には、利用者が明示的に開始する一括招待フローもあります。

元の拡張機能の機能を保持しています。初回は空の状態で、実際の連絡先、タスク履歴、ログインセッション、過去のバックアップは同梱していません。Creator Operations の企業向けバックエンドは不要です。

## 未送信の合成文案を確認する

リポジトリ全体のコピーと Node.js 24 を用意し、この拡張機能のディレクトリで次を実行します。

```sh
node ../../examples/assistant-demo.mjs
```

[サンプルのソース](../../examples/assistant-demo.mjs)は、この拡張機能のコアモジュールを使い、架空のクリエイター 2 人から未送信の文案を 2 件生成します。以下はソースとアサーションから確認できる想定出力です。今回のドキュメント整理ではコマンドを実行していません。

```json
{
  "mode": "synthetic-only",
  "creators": 2,
  "unsentDrafts": 2,
  "network": "none",
  "browser": "not opened",
  "persisted": false
}
```

この独立したサンプルはブラウザーを開かず、ネットワークにアクセスせず、記録を保存せず、招待も送信しません。拡張機能全体の実際の招待動作と権限については、以下を参照してください。

## ビルドとインストール

Node.js 24 が必要です。npm 依存パッケージはありません。

```sh
node build.mjs
node --test tests/*.test.mjs
```

ビルドでは自作のソースファイル 2 つを結合し、`capture-main.js` を生成するだけです。ダウンロード、パッケージのアップロード、ブラウザーへの拡張機能のインストールは行いません。

Chrome／Edge の専用テストプロファイルで拡張機能の管理ページを開き、デベロッパーモードを有効にして「パッケージ化されていない拡張機能を読み込む」からこのディレクトリを選びます。Manifest に記載された最小バージョンは Chrome 120 です。ブラウザーと Windows 実機での検証は行っておらず、この記載を検証済みの互換範囲とは扱いません。

## データと権限

- `storage` はローカルの記録を保存します。`activeTab`、`scripting`、限定されたプラットフォームの host permissions は、アクセス権のある現在のページの読み取りと、明示的に開始した操作に使います。`alarms` は招待タスクをスケジュールします。
- `cookies` は利用者が選んだ Weixin 店舗の現在のセッションを確認します。セッション値は実行時に該当プラットフォームへのリクエストにだけ使用します。ソースには Cookie、トークン、設定済みアカウントを含みません。
- 記録を第三者の競合サービスにアップロードしません。実際の招待フローは該当する公式プラットフォームと通信するため、拡張機能全体は完全なオフラインアプリではありません。
- ローカルへの記録はプラットフォーム上の担当登録ではなく、手動での完了マークは招待の到達確認でもありません。失敗、拒否、結果不明の場合は停止して人が確認し、無条件に再送しないでください。
- 既存設定では 1 回の処理は最大 50 人、間隔は最低 30 秒です。この制限はプラットフォームの利用許可や到達を保証しません。
- JSON バックアップ、CSV、ブラウザー保存領域、診断用エクスポートは利用者が管理し、ソースリポジトリに含めないでください。

## 検証範囲

ソース準備段階の過去の記録では、拡張機能の 164 件のテストが成功しています。今回はドキュメントの編集と静的チェックのみを行い、テストとビルドは再実行していません。

同梱する Node 単体テストは DOM、Chrome API、fetch、保存領域をモック化しています。元の非公開の過去の ZIP に依存する互換性テスト 1 件と、ブラウザーを起動する過去のスクリプトは除外しています。実際のプラットフォーム画面、ログイン、連絡先検索、招待送信、拡張機能ストアへの公開、Windows の検証は行っていません。
