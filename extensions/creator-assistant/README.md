# 达人助手 0.3.0 · 源代码候选

[English](README.en.md)

作者：xiaoyu312 · [FateClear — 免费的生日排盘与解读网站](https://fateclear.com) · [X — 作者项目与更新](https://x.com/liu_xiaoyu27334)

独立 Manifest V3 扩展：从用户当前已登录且有权访问的平台页面收录达人，在当前浏览器本地保存跟进、联系方式、筛选书签与邀约草稿。支持抖音精选联盟、视频号、小红书蒲公英、快手；抖音与视频号另有用户主动开始的批量邀约工作流。

本候选保留原扩展功能，不含真实联系人、任务、登录态或历史备份。首次使用为空状态。原完整达播中台不是运行本扩展的前提。

## 构建与测试

Node.js 24，无 npm 依赖。

```sh
node build.mjs
node --test tests/*.test.mjs
```

构建只将两个自己的源文件拼成 `capture-main.js`。没有下载、打包上传或安装浏览器扩展。

手动安装：在单独的 Chrome／Edge 测试配置中打开扩展管理页面，开启开发者模式，选择“加载已解压的扩展程序”，选择本目录。Manifest 声明的最低版本为 Chrome 120；本次没有浏览器或 Windows 实机验证，不把该字段当成已验证兼容范围。

## 数据与权限

- `storage` 保存本地记录；`activeTab`／`scripting` 与限定平台 host permissions 支持当前页读取和明确发起的操作；`alarms` 供邀约任务调度。
- `cookies` 用于用户所选视频号店铺的当前会话检查。会话值只在运行时用于对应平台请求；源包没有 Cookie、令牌或预设账户。
- 不把资料上传到第三方竞品服务；真实邀约会访问相应官方平台，不应描述为完全不联网。
- 收录不是平台认领；用户手动标记不是平台送达。失败、拒绝或未知结果应停止并人工核对，不能无条件重发。
- 原配置限制每批最多 50 位、至少 30 秒间隔。这些限制并不保证平台许可或送达。
- JSON 备份、CSV、浏览器存储与诊断导出由使用者保管；不要提交到源码仓库。
